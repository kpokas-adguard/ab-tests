# Поправки для ИИ-агента

Сюда пользователь записывает правила, которые агент понял неверно.
Агент читает этот файл вместе с `AGENT-BRIEF.md` и считает записи здесь
более приоритетными, чем общие правила брифа.

Агент **не пишет в этот файл сам** — только предлагает текст, пользователь сохраняет.

## Формат записи

```
## <Короткое название правила>
Дата: YYYY-MM-DD
Было: <как агент думал>
Верно: <как на самом деле>
```

## Не создавать и не менять без плана

Дата: 2026-09-11
Было: агент создал локальную карточку через `ab new` и записал факты
о тесте в `FACTS.md`, не спросив
Верно: перед созданием карточки, записью в `FACTS.md` и заменой уже
заполненного поля — показать план изменений и дождаться «да». Дозаполнять
пустые поля — можно без спроса. Факты о конкретном тесте — только
в `tests/<ключ>.md`, в `FACTS.md` — только окружение.
