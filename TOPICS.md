# Словарь тем — слова для поиска по Jira

Одна тема — одна строка. Слова через запятую, русские и английские,
как их реально пишут в заголовках задач. Агент ищет по заголовкам
(`summary ~`), поэтому важны именно те формы, что встречаются в названиях.

Правь руками: добавил слово — следующий поиск станет полнее. Агент сам
дописывает тему, только когда ты подтвердил набор слов в чате.
