По образцу ADG-12912. Заводится ПЕРВОЙ — dev-задача от неё зависит,
потому что `experiment_name` берётся отсюда.

# Описание

## Проблема

В сервисе A/B-тестирования отсутствует информация о тесте `<AG-XXXXX>`,
из-за чего невозможно корректно идентифицировать эксперимент и его гипотезу.

Добавить в сервис A/B-тестирования описание теста `<AG-XXXXX>`.

## Вводные данные

**Суть A/B теста:** `<одно предложение>`

**Цель:** `<какую метрику двигаем и зачем>`

**Версии:**
- `-a_def` — текущий UI (контроль)
- `-b` — `<новый UI>`

**Продукт:** `<AdBlocker>`
**Платформа:** `<Android>`
**Слот:** `<experiment_N>`

## Tech solution

1. Создать запись теста в сервисе A/B-тестирования.
   Название теста в сервисе:
   ```
   "experiment_name": "<AG-XXXXX-short-name>"
   ```

## Definition of Done

- [ ] Запись создана, `tests` возвращает назначение
- [ ] `experiment_name` передан в dev-задачу и совпадает с кодом клиента
