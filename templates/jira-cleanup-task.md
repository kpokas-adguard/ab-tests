# Описание

## Контекст

A/B-тест `<AG-XXXXX-short-name>` на слоте `<experiment_N>`, платформа `<...>`.
Решение по тесту: `<победитель / нет эффекта / вред>` — заполняется на шаге 9.

## ToDo

1. Пометить эксперимент **finished** в сервисе A/B-тестирования
   (`tests` перестаёт возвращать назначение по этому эксперименту).
2. Удалить эксперимент из кода клиента: обе ветки, флаг, условную логику.
3. Новым локальным дефолтом сделать `<победивший вариант>`.
4. Удалить или перевести в постоянную разметку события теста.
5. Освободить слот `<experiment_N>` — снять маппинг.

## Definition of Done

- [ ] Эксперимент помечен finished на бэке
- [ ] Код и флаг удалены из клиента
- [ ] Указана версия, в которой удалено: `<v4.16>`
- [ ] Эта версия вышла в релиз
- [ ] Слот `<experiment_N>` отмечен свободным в трекере (`ab slots`)

## Известное ограничение

Пользователи на версиях старее `<v4.16>` продолжают слать `experiment_*`
по закреплённому варианту. Полностью хвост исчезает только с оттоком старых версий
либо при смене маппинга слотов, что заставляет клиент сбросить закрепление.

**Пока флаг `finished` не реализован на бэке** — удаление из кода клиента
остаётся единственным рабочим способом остановить хвост.
