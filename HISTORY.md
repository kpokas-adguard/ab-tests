# Что уже пробовали — карта задач по теме

Навык для вопроса «что уже делали с онбордингом?» — до того, как
придумывать новый тест. Раньше тесты на бэке не регистрировались,
Research Board появился недавно, метка `Split-Testing` стояла не всегда.
Единственный полный след — задачи в Jira: дизайн и разработка.

**Цель — не результаты, а карта:** какие задачи были по теме, что в них
меняли, что из этого было тестом. Результаты в старых задачах не записаны —
не ищи их и не додумывай.

## Принцип экономии: ни одной задачи не открывай

Дорого — читать задачи. Дёшево — списки заголовков. Весь навык — три
поисковых запроса, только заголовки, группировка в голове. Открыть задачу —
только по прямой просьбе «раскрой AG-XXXXX».

## Шаг 1 — слова

Тема — из сообщения. Открой `TOPICS.md`.

- Тема есть → бери слова, не спрашивай.
- Темы нет → предложи 6–10 слов на двух языках, как их пишут в заголовках
  задач, и спроси одним сообщением:

  > Ищу по словам: onboarding, онбординг, first run, … Добавить или убрать?

  После ответа — подтверждение «Мне записать тему в TOPICS.md?» и запись.

## Шаг 2 — три запроса, по заголовкам

`jira_search_issues`, `maxResults: 50`, все продукты — идея из VPN или
с сайта полезна блокировщику. Слова — цепочкой `summary ~ "w1" OR summary ~ "w2" …`,
ниже это `<слова>`.

| # | JQL | Что ловит |
| - | --- | --------- |
| A | `labels = Split-Testing AND (<слова>) ORDER BY created DESC` | помеченные тесты |
| B | `component = Design AND (<слова>) AND created >= -3y ORDER BY created DESC` | всё, что рисовали по теме: тесты без метки и изменения |
| C | `issuetype = Task AND component != Design AND (<слова>) AND created >= -3y ORDER BY created DESC` | разработка без дизайна |

Проекты: `AG` и всё, что про сайт и лендинги — «AdGuard Web». Где это
(проект или компонент) — посмотри в `FACTS.md`, раздел «Jira: AdGuard Web»;
нет раздела — найди через `jira_list_project_components` для `AG` по слову
`Web`, не нашёл — спроси, и запиши в FACTS через `ab fact set`.

Из ответа бери только: ключ, заголовок, тип, компоненты, метки, статус,
год создания, эпик/родитель, если есть. Описания не читай.

**Если `total` больше 50 в любом запросе** — не листай. Покажи счёт:

> По «онбординг» в дизайне 140 задач. Сузить: убрать слово «welcome»,
> ограничить двумя годами, или взять 50 свежих?

## Шаг 3 — склей и пометь

Без Jira, по заголовкам:

- одна попытка = один эпик, или дизайн + разработка с одним названием,
  или одна версия и одна платформа
- платформа — по компоненту (`Windows: AdGuard`, `Extensions: VPN`, …)
- тип:
  - **тест** — метка `Split-Testing`, или в заголовке `A/B`, `AB`, `вариант B`,
    `эксперимент`, `тест`
  - **похоже на тест** — изменение поведения без метки: «новый экран»,
    «упростить», «показать X вместо Y», «убрать шаг»
  - **изменение** — остальное по теме: правки текста, баги, редизайн
- подтемы — по смыслу заголовков: «первый экран», «платный онбординг»,
  «лендинг» — 3–6 групп, не больше

## Шаг 4 — ответ

```
Онбординг — что трогали, 2023–2026 · 14 задач · 5 тестов

Первый экран после EULA
  AG-41205  Extension · 2024 · тест        Показывать ExtensionScreen сразу
  AG-38812  Windows · 2023 · изменение     Убрать шаг выбора фильтров
Платный онбординг
  AG-52740  Android · 2025 · тест          Оффер после третьего экрана
Сайт
  AG-…      Web · 2024 · похоже на тест    Новый первый экран лендинга

Пусто по этим словам: iOS, Mac Mini.
Слова: onboarding, онбординг, first run, … — правь в TOPICS.md.
Раскрыть задачу — «раскрой AG-41205».
```

Что обязательно: год, платформа, тип, заголовок как в Jira. Что запрещено:
результат теста, если его нет в заголовке; оценки «скорее всего не сработало».

## Шаг 5 — кэш

Ответ сохрани в `history/<тема>.md` с датой поиска и словами. Это общая
база «что пробовали» — она в git, ей пользуются все продакты.

Следующий раз по той же теме: сначала файл, потом те же три запроса
с `created >= <дата последнего поиска>` — дозапрос новых. Слова изменились —
полный поиск заново.

## Внутри подготовки карточки

Шаг 1б в `RESEARCH-CARD.md`: после разведки телеметрии, до гипотезы —
запусти этот сценарий по теме теста без вопросов, покажи карту, спроси
одно: «Что из этого важно учесть?» Ответ — в поле `prior_art` карточки
(ссылка на `history/<тема>.md` и 1–2 строки вывода).
